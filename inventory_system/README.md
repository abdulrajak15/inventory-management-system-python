# Inventory Management System

A database-driven Python console application to manage inventory,
track products, and generate reports — built for the Advance Stage
Project 1 brief (Cognetix internship).

## Features

- **CRUD operations** — Add, Update, Delete, View products
- **Validations** — unique Product ID, numeric quantity/price checks
- **Reporting** — low-stock report + inventory summary (total
  products, total stock, total inventory value), saved to
  `reports/low_stock.txt` and `reports/summary.txt`
- **Bulk update** — insert/update many products at once from a CSV
  file
- **Clean modular code** — `db.py` handles all database access,
  `app.py` holds business logic (`InventoryManager` class) and the
  console menu, `config.py` holds settings
- **Exception handling** throughout, so bad input never crashes the app

## Project Structure

```
inventory_system/
```

## How to Run

### 1. Requirements

- Python 3.8+

That's it, if you use the default database mode (see below).

### 2. Choose your database backend

Open `config.py` and set `DB_TYPE`:

**Option A — SQLite (default, zero setup)**
```python
DB_TYPE = "sqlite"
```
No install or server needed — a file called `inventory.db` is
created automatically the first time you run the app. This is the
fastest way to test everything end to end.

**Option B — MySQL (matches the project's "Recommended for
Enterprise Projects" option)**
```python
DB_TYPE = "mysql"
```
Then:
```bash
pip install -r requirements.txt
```
And fill in your server details in `config.py`:
```python
MYSQL_HOST = "localhost"
MYSQL_USER = "root"
MYSQL_PASSWORD = "your_password"
MYSQL_DATABASE = "inventory_db"
```
Create the database first (the app creates the `products` table for
you, but not the database itself):
```sql
CREATE DATABASE inventory_db;
```

### 3. Run the app

```bash
python app.py
```

You'll see the main menu:
```
1. Add Product
2. Update Product
3. Delete Product
4. View Inventory
5. Reports
6. Bulk Update
7. Exit
```

### 4. Try the Bulk Update feature

A sample `bulk_update.csv` is included. From the menu, choose
option `6` and enter `bulk_update.csv` when prompted. Existing
Product IDs get updated; new ones get inserted.

CSV format:
```
product_id,name,category,quantity,price
101,Keyboard,Electronics,50,499.00
102,Mouse,Electronics,80,299.00
```

## Database Schema (`products` table)

| Field        | Type              | Description                     |
|--------------|-------------------|----------------------------------|
| product_id   | VARCHAR / TEXT    | Primary key, unique              |
| name         | VARCHAR / TEXT    | Product name                     |
| category     | VARCHAR / TEXT    | e.g. electronics, food           |
| quantity     | INT               | Current stock quantity           |
| price        | DECIMAL(10,2)     | Price per unit                   |
| added_on     | TIMESTAMP         | Auto timestamp on insert         |

## Notes

- The low-stock threshold (default `10`) is configurable in
  `config.py` via `LOW_STOCK_THRESHOLD`.
- Switching `DB_TYPE` between `"sqlite"` and `"mysql"` is the only
  change needed anywhere — `app.py` and `db.py`'s public functions
  work identically on both backends.
